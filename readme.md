# ✅ Task Organizer – Vanilla JS, HTML & CSS CRUD Project

This is a task management web app built to practice and demonstrate **JavaScript, HTML, and CSS** skills.  
The interface allows users to create, edit, delete, and categorize tasks in a clean and organized layout with modal interaction.

🧠 Ideal for beginners learning CRUD operations with a fake API (JSON Server).

## 📁 Project Structure

- `index.html` – main HTML file containing task columns and modal  
- `style.css` – modern and responsive CSS styles for layout and modal  
- `public/img/` – icons and visual assets  
- `src/js/app.js` – main logic file (renders tasks, handles form and events)  
- `src/js/dom.js` – UI and DOM manipulation logic  
- `src/js/service.js` – API calls (GET, POST, PUT, DELETE) using `fetch()`  
- `db.json` – mock database file used by JSON Server

## 📌 Notes

- All data is stored locally using **JSON Server** (`http://localhost:3000/tasks`)  
- No frameworks or libraries used — pure JavaScript  
- The UI includes modal support, form validation, and duplicate title prevention  
- Tasks are filtered by status:
  - ⏳ Pending
  - 🕒 On Hold
  - 🚧 In Progress
  - ✅ Completed
